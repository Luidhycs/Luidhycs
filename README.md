### 💼 Projetos Realizados

### | Sistema de Gestão Hospitalar — Hospital São Rafael

- **Descrição:** Aplicação web completa desenvolvida para o ambiente de Roleplay (RP), integrando processos clínicos e administrativos em uma única plataforma. O sistema reúne gerenciamento de pacientes e profissionais, prontuários, agendamentos, exames, laudos, acompanhamento médico, documentos e portais de acesso, com autenticação e controle de permissões.
- **Tecnologias:** Next.js, React, JavaScript, Supabase, PostgreSQL, HTML e CSS.
- **Desenvolvimento:** Arquitetura da aplicação, modelagem de dados, interfaces, integração de serviços e implementação de funcionalidades.
- **Status:** Projeto concluído, com evolução e aprimoramentos realizados durante sua utilização.
- **Acesso:** Sistema privado, desenvolvido exclusivamente para o Hospital São Rafael de Eldorado (RP).
